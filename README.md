### 🚀 Projeto em Destaque

**[UsbScreamer](https://usb-screamer.vercel.app)** — Utilitário desktop cômico e minimalista para Windows que reage sonoramente à conexão e desconexão de dispositivos removíveis (USB).
- **Engenharia de Baixo Nível:** Detecção contínua via polling com a Windows API (`ctypes`), garantindo a preservação dos handles para ejeção segura nativa do Windows.
- **Interface & Sistema:** Execução silenciosa na bandeja do sistema (`pystray`), reprodução de áudio assíncrona desacoplada (`winsound`) e persistência segura no Registro (`winreg`).
- **Automação de Build & Distribuição:** Script de compilação 1-clique com PyInstaller e instalador nativo empacotado via Inno Setup (execução isolada em `%LocalAppData%` sem necessidade de privilégios de administrador/UAC).
